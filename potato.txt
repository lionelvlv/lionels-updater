# Potato mode (update.ps1 and update_linux.py, step 5p; 2026-10-21, Lionel: "a super low-spec pc complete with options
# and settings recommended for a potato"; "maximum cuts for maximum performance"; "8gb is the potato mode starter").
# The player says yes or no on every run but the launch check's (Enter keeps). On: the lines below are applied and what
# they replaced is written down in the instance (lionels-updater-potato.txt); off again: all of it goes back. A setting
# the player changed themselves while in potato mode is left as they set it. The optional mods (optional.txt) are all
# off while potato mode is on; the player's own choices come back with it off. Memory: 8 GB.
#
# mod|<mod id>|<name>      every jar declaring that mod id is renamed .jar.disabled. Only mods the server does not have
#                          and that nothing else needs. NOT here, on purpose: Entity Model/Texture/Sound Features
#                          (Villager News requires all three; their settings below make them cheap instead).
# pack|<entry>|off|on      a resource pack entry in options.txt: off = taken out of the list (a * at the end matches any
#                          rest of the name), on = added at the end (only if the pack is in resourcepacks).
# set|<file>|<kind>|<section>|<key>|<value>
#                          kind kv: options.txt "key:value"; json: "key": value, searched from "section": { (- = from the
#                          top); toml: key = value inside [section] (- = above the first section). The value is written as it stands here. Each key and
#                          value was checked against the mod's own config class (javap, 2026-10-21).
